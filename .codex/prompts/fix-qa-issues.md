- QA reports are in `docs/qa`, find the issues report file `$ARGUMENTS`.
- Fix those issues that are not blocked by bugs from the engine already reported in `BUG_REPORTS.md`.
- If you cannot fix the issues due to engine problems, add the engine bug report to `BUG_REPORTS.md`.
- Mark issues that are fixed as completed in the issues report file `$ARGUMENTS`.
